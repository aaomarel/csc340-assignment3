# csc340-assignment3
Simple CRUD API for Marine Animal Objects with JPA (Hibernate)

### Version
1.0.0

## Installation
- Get the project
    - clone
        ```
      git clone https://github.com/aaomarel/csc340-assignment3.git
        ```
    - OR download zip.
- Open the project in VS Code.
- This project is built to run with jdk 17.
- [Dependencies](https://github.com/aaomarel/csc340-assignment3/blob/main/build.gradle) to JPA and Postgres in addition to the usual Spring Web. JPA handles the persistence, Postgresql is the database to be used.
- `/src/main/resources/application.properties` This file has the configuration for the PostgreSQL database to use for the API.
  - You MUST have the database up and running before running the project!
    - Login to your neon.tech account.
    - Locate your database project.
    - On the project dashboard, click on "Connect" and select Java.
    - Copy the connection string provided.
    - Paste it as a value for the property `spring.datasource.url`. No quotation marks.
- Build and run the main class. You should see a new table created in the Neon database.

## API Endpoints
Base URL: [`http://localhost:8080/api/marineanimals`](http://localhost:8080/api/marineanimals)


1. ### [`/`](http://localhost:8080/api/marineanimals) (GET)
Gets a list of all Marine Animals in the database.

#### Response - A JSON array of MarineAnimal objects.

 ```
[
  {
    "animalId": 1,
    "name": "Blue Whale",
    "description": "The largest animal on Earth",
    "species": "Balaenoptera musculus",
    "habitat": "Open ocean"
  },
  {
    "animalId": 2,
    "name": "Clownfish",
    "description": "Small, colorful reef fish",
    "species": "Amphiprioninae",
    "habitat": "Coral reefs"
  }
]
```

2. ### [`/{animalId}`](http://localhost:8080/api/marineanimals/1) (GET)
Gets an individual Marine Animal in the system. Each Marine Animal is identified by a numeric `animalId`

#### Parameters
- Path Variable: `animalId` &lt;Long&gt; - REQUIRED

#### Response - A single MarineAnimal

```
  {
    "animalId": 1,
    "name": "Blue Whale",
    "description": "The largest animal on Earth",
    "species": "Balaenoptera musculus",
    "habitat": "Open ocean"
  }
```

3. ### [`/search`](http://localhost:8080/api/marineanimals/search?name=whale) (GET)
Gets a list of marine animals with a name that contains the given string.

#### Parameters
- query parameter: `name` &lt;String&gt; - REQUIRED

#### Response - A JSON array of MarineAnimal objects.

```
[
  {
    "animalId": 1,
    "name": "Blue Whale",
    "description": "The largest animal on Earth",
    "species": "Balaenoptera musculus",
    "habitat": "Open ocean"
  },
  {
    "animalId": 4,
    "name": "Killer Whale",
    "description": "Actually a dolphin, apex predator",
    "species": "Orcinus orca",
    "habitat": "All oceans"
  }
]
```

4. ### [`/species/{species}`](http://localhost:8080/api/marineanimals/species/Amphiprioninae) (GET)
Gets a list of marine animals for a named species.

#### Parameters
- path variable: `species` &lt;String&gt; - REQUIRED

#### Response - A JSON array of MarineAnimal objects.

```
[
  {
    "animalId": 2,
    "name": "Clownfish",
    "description": "Small, colorful reef fish",
    "species": "Amphiprioninae",
    "habitat": "Coral reefs"
  }
]
```

5. ### [`/`](http://localhost:8080/api/marineanimals) (POST)
Create a new Marine Animal entry

#### Request Body
A MarineAnimal object. Note the object does not include an ID as this is autogenerated.
```
{
  "name": "Great White Shark",
  "description": "Large predatory shark",
  "species": "Carcharodon carcharias",
  "habitat": "Coastal waters"
}
```
#### Response - The newly created MarineAnimal.

```
  {
    "animalId": 3,
    "name": "Great White Shark",
    "description": "Large predatory shark",
    "species": "Carcharodon carcharias",
    "habitat": "Coastal waters"
  }
```

6. ### [`/{animalId}`](http://localhost:8080/api/marineanimals/3) (PUT)
Update an existing Marine Animal.

#### Parameters
- Path Variable: `animalId` &lt;Long&gt; - REQUIRED

#### Request Body
A MarineAnimal object with the updates.
```
{
  "name": "Great White Shark",
  "description": "Large predatory shark found in cool coastal waters",
  "species": "Carcharodon carcharias",
  "habitat": "Cool coastal waters worldwide"
}
```
#### Response - the updated MarineAnimal object.
```
{
  "animalId": 3,
  "name": "Great White Shark",
  "description": "Large predatory shark found in cool coastal waters",
  "species": "Carcharodon carcharias",
  "habitat": "Cool coastal waters worldwide"
}
```

7. ### [`/{animalId}`](http://localhost:8080/api/marineanimals/3) (DELETE)
Delete an existing Marine Animal.

#### Parameters
- Path Variable: `animalId` &lt;Long&gt; - REQUIRED

#### Response - No content (204).
```
No Content
```
